Logistic Regression – Concepts

What is Logistic Regression?

Logistic Regression is a statistical model used for binary classification problems, where the outcome can only take two possible values (such as 0/1, yes/no, positive/negative). It uses the logistic (sigmoid) function to transform linear combinations of input variables into probabilities between 0 and 1. This makes it especially useful when the goal is to estimate the likelihood of an event occurring.

Why is Logistic Regression a Classification Algorithm?

Unlike linear regression, which predicts continuous values, logistic regression predicts discrete categories. By mapping inputs to probabilities and applying a threshold, it assigns each observation to one of two classes. This makes it a fundamental classification algorithm widely used in statistics and machine learning.

What is Binary Classification?

Binary classification refers to problems where the target variable has only two possible outcomes. Examples include predicting whether an email is spam or not, whether a patient has a disease or not, or whether a transaction is fraudulent or legitimate.

Independent Variable

The independent variable (X) is the input feature used to predict the outcome. For example, in a medical context, it could be a patient’s age or blood pressure. Logistic regression uses these variables to estimate the probability of belonging to a particular class.

Dependent or Target Variable

The dependent variable (y) is the output we want to predict. In logistic regression, it must be binary, meaning it can only take two values. For example: 0 = No disease, 1 = Disease.

Classes or Labels

Classes represent the categories of the target variable. Logistic regression assigns each observation to one of these labels based on the predicted probability. Examples: 0 = Low Risk, 1 = High Risk.

Probability of Belonging to a Class & Threshold

Logistic regression outputs probabilities between 0 and 1. To make a decision, a classification threshold is applied (commonly 0.5). If the probability is greater than or equal to the threshold, the observation is classified as 1; otherwise, it is classified as 0.

Difference between Linear Regression and Logistic Regression

Linear regression predicts continuous values, such as house prices or sales numbers. Logistic regression, on the other hand, predicts categorical outcomes by modeling probabilities. While linear regression fits a straight line, logistic regression fits an S-shaped curve (sigmoid function) to map inputs to probabilities.
