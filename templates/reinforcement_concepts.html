Reinforcement Learning – Concepts

In this exercise, the agent is a virtual robot moving inside a maze. Its possible actions are: Up, Down, Left, Right. It receives rewards (+20 when reaching the goal) and penalties (−1 per move, −5 when hitting a wall).
What is Reinforcement Learning?

Reinforcement Learning is a learning paradigm where an agent interacts with an environment, takes actions, and receives feedback in the form of rewards or penalties. The goal is to learn a policy that maximizes cumulative reward over time.

Agent

The agent is the decision-maker in Reinforcement Learning. In our maze example, the agent is the virtual robot that chooses whether to move up, down, left, or right.

Its role is not passive: the agent actively explores the environment, learns from mistakes, and gradually improves its strategy. Each decision affects future outcomes, making the agent responsible for balancing short-term penalties with long-term rewards.

The agent’s ultimate goal is to reach the maze’s exit while maximizing cumulative reward.
Environment

The environment defines the world in which the agent operates. In our case, it is the maze with walls, open paths, and a goal position.

It provides feedback to the agent: valid moves lead to new states, while invalid moves (hitting walls or going outside the grid) result in penalties. The environment is static but unforgiving, forcing the agent to adapt its behavior.

The environment shapes the agent’s learning process by controlling rewards and penalties.

Epsilon-greedy Strategy

The epsilon-greedy strategy balances exploration and exploitation. With probability ε, the agent explores by choosing a random action. With probability 1−ε, it exploits by choosing the best known action.

This ensures the agent does not get stuck repeating the same path and continues to discover potentially better routes.

Example: ε = 0.2 → 20% explore, 80% exploit.

High (0.8)Mostly exploration, less exploitation

Q-Learning

Q-Learning is a powerful algorithm that allows the agent to learn the optimal policy without knowing the environment’s dynamics in advance.

It updates the value of each state-action pair based on observed rewards and estimated future returns:

Q ← Q + α [r + γ max Q(s',a') − Q]

Where:

  • α = learning rate (how fast the agent updates knowledge)
  • r = immediate reward
  • γ = discount factor (importance of future rewards)
  • s' = next state
Q-Learning enables the agent to discover the shortest and most rewarding path through trial and error.
